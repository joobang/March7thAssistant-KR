# 삼칠이 도우미

**March7thAssistant-KR**은 붕괴: 스타레일 자동화 도구 [March7thAssistant](https://github.com/moesnow/March7thAssistant)의 비공식 한국어 현지화 포크입니다.

현재 한국어 UI에서 앱 이름을 **삼칠이 도우미**로 표시합니다. 앱 UI는 설정에서 `한국어`로 바꿀 수 있습니다. 게임 화면 인식과 자동화는 원본에서 지원하는 중국어 간체 게임 화면을 기준으로 동작합니다.
